## Kalan riskler

- Ayrı ağ/volume/anahtar ayrımı var; **aynı EC2, disk ve Docker daemon** kullanılıyor. Host veya disk arızası iki ortamı etkileyebilir. Yeni ücretli altyapı eklenmedi.
- `unhealthy` etiketi tek başına Docker restart tetiklemez. İşlem çökmesinde restart doğrulandı; süreç yaşıyor ama kilitlenmişse mevcut SNS izleme uyarır, operatör müdahalesi gerekir. Yeni autoheal servisi eklenmedi.
- Host tamamen durursa aynı hosttaki cron uyarı gönderemez. Harici uptime servisi/CloudWatch altyapısı eklenmedi.
- IAM sınırı nedeniyle S3 versioning/lifecycle politikası ve SNS aboneliğinin onay durumunu bu rol üzerinden teyit etmek mümkün değil. Nesne AES256 ve gerçek restore doğrulandı; gerçek e-posta teslimatı varsayılmadı.
